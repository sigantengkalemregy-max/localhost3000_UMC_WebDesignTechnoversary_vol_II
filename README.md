# Jejak Sebotol

Website edukasi dan kampanye lingkungan: perjalanan satu botol plastik dari tangan kita, ke sungai, ke laut, sampai kembali ke piring kita. Pengunjung juga bisa menghitung plastik sekali pakai dan mencentang aksi nyata.

Dibuat untuk Web Design Competition, Techno Versary Vol. II (tema EcoDigital For Environment).

Demo: https://sigantengkalemregy-max.github.io/webdesign_localhost3000_technoversary_vol.II/

## Halaman
- `index.html` (Home), `cerita.html` (halaman Konten: scrollytelling 5 adegan), `aksi.html` (kalkulator dan checklist), `about.html` (About), `contact.html` (Contact)

## Cara menjalankan
1. Unduh atau clone repository ini.
2. Buka `index.html` di browser. Tidak perlu instalasi apa pun.
3. Opsional: buka folder di VS Code dan jalankan ekstensi Live Server.

## Struktur
- `css/style.css` dan `css/animations.css`: tampilan, warna tiap adegan, dan animasi
- `js/script.js`: perubahan tema saat scroll, panggung botol, hitung-naik angka, kalkulator, checklist, formulir kontak
- `assets/`: ilustrasi SVG

## Teknologi
HTML, CSS, dan JavaScript murni. Font: Fraunces dan Inter (Google Fonts, gratis).

## Transparansi proses
Tim memakai asisten AI (Claude) untuk membantu menyusun kode, ilustrasi SVG, dan riset sumber data. Seluruh isi, angka, dan sumber ditinjau dan diuji oleh tim sebelum dikumpulkan.
